# Pulse Labs

A SaaS product surface showing how data, members, workflow signals, and custom dashboards can sit on a Wix Headless foundation.

This website is powered by Wix Headless and built using [wix-headless.dev](https://www.wix-headless.dev).

## Live Site

- [https://pulse-labs-acc09c00-gonenj.wix-site-host.com](https://pulse-labs-acc09c00-gonenj.wix-site-host.com)

## Source

- [https://github.com/wix-incubator/pulselabs](https://github.com/wix-incubator/pulselabs)

## What It Showcases

- SaaS experience built as a custom headless website
- Wix-managed backend capabilities surfaced through a custom Astro front end
- Public `llms.txt` and `robots.txt` configured through the Wix SEO txt APIs
- Deployment with `wix release`

## Local Development

```bash
yarn install
yarn dev
```

## Build

```bash
yarn build
```
